# CLAUDE.md

The instructions for AI coding agents working on this repository live in
**[AGENTS.md](AGENTS.md)** — build commands, module layout, the client-parity
contract, code style, and the subsystems where a change needs a conversation
first.

This file exists so that harnesses which look for `CLAUDE.md` by name find
their way there. It is a pointer, not a second copy: two files drift, and the
one you happened to load would be the stale one.

If you are an agent *running inside* Wyrdsekai as a companion rather than
working on its source, the document addressed to you is
[docs/LETTER_TO_AGENTS.md](docs/LETTER_TO_AGENTS.md).
