ncps — Neural Circuit Policies

ncps is the reference Python implementation of Neural Circuit Policies, including Liquid Time-constant (LTC) networks and the Closed-form Continuous-time (CfC) approximation introduced by Hasani et al. The library is the canonical companion code for the Liquid Neural Networks line of work out of MIT CSAIL.

Installation

pip install ncps

Optional: pip install ncps[tf] for the TensorFlow backend.

Quick start (PyTorch)

from ncps.torch import LTC
from ncps.wirings import AutoNCP

wiring = AutoNCP(units=19, output_size=4)
model = LTC(input_size=2, units=wiring)

The AutoNCP wiring lays the 19 neurons out into the four-layer C. elegans-inspired topology (sensory → inter → command → motor). For most time-series tasks units=19 is sufficient — the LTC's ODE-based dynamics replace what would otherwise need hundreds of GRU cells.

LTCCell vs CfCCell

CellCost per stepUse when
LTCCell1-3 ODE solver iterationsYou need provable bounded continuous-time dynamics. Slower at inference but expressive.
CfCCellOne closed-form formulaYou want LTC-like behaviour with the wallclock cost of a vanilla RNN. Recommended default for embedded targets.
